1. Definiciones

En estos términos, "Sistema" se refiere al sitio web, aplicación web y móvil, panel de administración, base de datos, servicios de pedidos y herramientas ofrecidas por Flipside Burgers Inspired. "Usuario" es cualquier persona que accede, navega o utiliza nuestros servicios. "Cliente" es quien realiza un pedido o compra productos dentro de nuestro sistema.

2. Condiciones Generales de Uso

El usuario acepta usar este sistema únicamente para fines legales y conforme a las leyes vigentes. Está estrictamente prohibido:

  • Realizar actividades que puedan dañar o alterar el funcionamiento del sistema.
  • Crear cuentas falsas o usar información fraudulenta.
  • Intentar acceder a áreas restringidas, servidores o bases de datos.
  • Modificar, distribuir, copiar o reproducir contenido sin autorización.

3. Cuentas de usuario y seguridad

El usuario es responsable de mantener su cuenta segura, incluyendo su contraseña y dispositivo de acceso. Nos reservamos el derecho de suspender cuentas que presenten actividad sospechosa.

Responsabilidades del usuario:

  • Mantener la información personal actualizada y verídica.
  • No compartir credenciales de acceso.
  • Reportar accesos no autorizados inmediatamente.

4. Privacidad y Protección de Datos

El sistema almacena información necesaria para el funcionamiento de la plataforma, como nombre, correo, teléfono y pedidos. No vendemos ni compartimos información personal con terceros sin autorización del usuario, excepto por obligación legal.

El usuario puede solicitar eliminación o modificación de sus datos personales.

5. Pedidos, Pagos y Entregas

Al realizar un pedido el usuario acepta:

  • Proporcionar datos reales y correctos de entrega.
  • Realizar pago según el método disponible (en línea o al recibir según el local).
  • Las modificaciones o cancelaciones solo son posibles antes de que el pedido entre en preparación.

6. Propiedad Intelectual

Todo contenido del sistema, incluyendo imágenes, logotipos, menús, diseños, textos, software, scripts y estilos, pertenece a Flipside Burgers Inspired. Queda prohibido su uso sin autorización escrita.

7. Limitación de Responsabilidad

No somos responsables por interrupciones de servicio causadas por factores externos como fallas técnicas, proveedores externos, ataques digitales o eventos fuera de control.

No garantizamos disponibilidad permanente del servicio, aunque trabajamos para mantenerlo estable y seguro.

8. Modificaciones del Servicio

Podemos modificar menús, precios, disponibilidad de productos, funciones del sistema o estos términos sin notificación previa cuando sea necesario para operación y seguridad.

9. Suspensión y Terminación

Nos reservamos el derecho de suspender o eliminar cuentas por actividades ilegales, abuso del sistema o incumplimiento de términos.

10. Ley Aplicable

Estos términos se rigen bajo las leyes de México. En caso de disputa, las autoridades correspondientes de México serán quienes determinen resolución.

11. Contacto

Para dudas o aclaraciones, escribe a: soporte@flipsideburgers.com

10. Políticas de Envíos y Entregas

Las órdenes se procesan en el orden en que son recibidas. El tiempo de entrega puede variar dependiendo de la disponibilidad de productos, ubicación del cliente y carga operativa. El Usuario será notificado en caso de retrasos significativos. La entrega se considera completada al momento de llegar a la dirección proporcionada en el pedido.

11. Reembolsos, Cancelaciones y Devoluciones

Por tratarse de alimentos preparados, las devoluciones no aplican salvo error comprobable en pedido o defecto en productos. Para solicitar reembolso, el Usuario deberá presentar evidencia fotográfica y ticket digital dentro de las primeras dos horas posteriores a la compra. El negocio se reserva el derecho de analizar y determinar si procede.

12. Conducta del Usuario

El Usuario se compromete a utilizar el sistema de manera responsable, sin generar contenidos ofensivos, fraudulentos, difamatorios o cualquier acción que afecte la operación y reputación del negocio. Se prohíbe el uso del sistema para actividades ilícitas o automatización sin consentimiento.

13. Seguridad del Sistema y Disponibilidad

El sistema puede estar sujeto a mantenimientos, actualizaciones o fallas técnicas. No garantizamos disponibilidad ininterrumpida del servicio, pero trabajaremos para restaurarlo lo más pronto posible. El Usuario acepta que las interrupciones no generan responsabilidad ni compensación automática.

14. Protección de Datos y Privacidad

La información del Usuario será protegida y utilizada únicamente para fines operativos, administrativos y comerciales del negocio, conforme a normas aplicables de protección de datos. No se comparte información con terceros sin autorización expresa del Usuario, salvo obligación legal.

15. Modificaciones a los Términos

El negocio puede actualizar estos términos en cualquier momento con el fin de mejorar el servicio y cumplir con normativas vigentes. Las modificaciones entran en vigor al ser publicadas en esta página. Se recomienda revisar esta sección regularmente.

16. Legislación Aplicable

Estos términos serán regidos por las leyes aplicables en la jurisdicción donde opera el negocio. En caso de conflicto, las partes se someterán a las autoridades competentes que correspondan.

17. Contacto

Para dudas, aclaraciones o solicitudes relacionadas con estos términos y condiciones, el Usuario puede contactarnos mediante los medios oficiales de comunicación publicados en el sistema.
